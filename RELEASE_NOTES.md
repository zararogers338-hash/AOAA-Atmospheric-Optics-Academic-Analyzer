# AOAA Atmospheric Optics Academic Analyzer v3.3 Open Source Preview

AOAA is an open-source Streamlit workbench that analyzes academic literature through atmospheric optics metaphors.

AOAA / 学术大气光学分析器 是一个开源 Streamlit 工作台，它使用大气光学隐喻来分析学术文献、研究方法和领域结构。

## English

This is the first open-source preview release of **AOAA Atmospheric Optics Academic Analyzer v3.3**.

The project converts academic documents into keyword statistics, co-occurrence networks, trend charts, atmospheric metaphor categories, and optional AI-assisted interpretations.

AOAA uses nine atmospheric optical phenomena as academic observation lenses:

- Aurora: high-impact breakthrough methods
- Noctilucent Clouds: far-horizon frontier methods
- Nacreous Clouds: rare precision methods
- Asperitas: turbulent or controversial methods
- Lenticular Clouds: stable symmetric methods
- Circumhorizontal Arc: ultra-pure precision methods
- Fallstreak Hole: human-triggered cascade methods
- Brocken Spectre: observer-centric methods
- Moonbow: low-light or weak-signal methods

AOAA is intentionally atmospheric and optical. It does not use biological, ecological, species, predator, extinction, or carbon-sink metaphors.

## 中文

这是 **AOAA Atmospheric Optics Academic Analyzer / 学术大气光学分析器 v3.3** 的第一个开源预览版本。

本项目可以把学术文档转化为关键词统计、共现网络、趋势图表、大气隐喻类别和可选的 AI 辅助解释。

AOAA 使用九种大气光学现象作为学术观测镜头：

- 极光：高影响力突破方法
- 夜光云：远期前沿方法
- 珠母云：珍稀精密方法
- Asperitas：剧烈扰动或争议方法
- 透镜云：稳定对称方法
- 火彩虹：高纯度精准方法
- 陨落孔：人为触发连锁方法
- 布罗肯幽灵：观测者中心方法
- 月虹：低亮度或弱信号方法

AOAA 的概念语言被刻意限制在大气和光学系统之内。它不使用生物学、生态学、物种、捕食者、灭绝或碳汇等隐喻。

## Installation / 安装

```bash
git clone https://github.com/zararogers338-hash/AOAA-Atmospheric-Optics-Academic-Analyzer.git
cd AOAA-Atmospheric-Optics-Academic-Analyzer
pip install -r requirements.txt
streamlit run app.py
```

## Important Notice / 重要说明

AOAA is not an academic evaluation authority, not a citation ranking system, and not a final judgment tool.

AOAA 不是学术评价权威，不是引用排名系统，也不是最终裁决工具。

Its atmospheric-optics metaphors are observation tools. They are meant to help users see patterns, not replace scholarly expertise or peer review.

它的大气光学隐喻是观测工具，用来帮助用户发现模式，而不是替代学术专家判断或同行评议。

## Project Status / 项目状态

This is an open-source preview release. Some modules are experimental and should be treated as research prototypes.

这是一个开源预览版本。部分模块仍具有实验性质，应当被视为研究原型。
