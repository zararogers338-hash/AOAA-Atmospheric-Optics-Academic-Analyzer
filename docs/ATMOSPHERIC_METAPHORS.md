# Atmospheric Optics Metaphors / 大气光学隐喻

AOAA uses atmospheric optics as a disciplined metaphor system for academic analysis.

AOAA 使用大气光学作为学术分析的约束性隐喻系统。

It intentionally avoids biological/ecological language. The goal is to describe academic fields through light, scattering, visibility, altitude, turbulence, horizon effects, observer effects, and weak-signal phenomena.

它刻意避免生物学和生态学语言，目标是通过光、散射、可见度、高度、湍流、地平线效应、观测者效应和弱信号现象来描述学术场。

## Nine lenses / 九种观测镜头

1. Aurora / 极光: high-impact breakthrough methods
2. Noctilucent Clouds / 夜光云: far-horizon frontier methods
3. Nacreous Clouds / 珠母云: rare precision methods
4. Asperitas: turbulent or controversial methods
5. Lenticular Clouds / 透镜云: stable symmetric methods
6. Circumhorizontal Arc / 火彩虹: ultra-pure precision methods
7. Fallstreak Hole / 陨落孔: human-triggered cascade methods
8. Brocken Spectre / 布罗肯幽灵: observer-centric methods
9. Moonbow / 月虹: low-light / weak-signal methods
