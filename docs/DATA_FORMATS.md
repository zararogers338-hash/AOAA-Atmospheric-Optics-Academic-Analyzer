# Data Formats / 数据格式

AOAA accepts many document formats through `utils/file_parser.py`.

AOAA 通过 `utils/file_parser.py` 支持多种文档格式。

Supported or partially supported:

- TXT / MD
- PDF
- DOCX / DOC
- CSV / TSV
- XLSX / XLS
- JSON / JSONL
- HTML / XML
- YAML
- Web of Science text exports
- RIS
- BibTeX

Parsing quality depends on the source file structure and installed optional dependencies.

解析质量取决于源文件结构和可选依赖是否安装。
